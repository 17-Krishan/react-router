# React Router Playground

A simple React application built to learn React Router concepts such as nested routes, dynamic routes, route parameters, loaders, and navigation using Link and NavLink.

## Features

- Dynamic User Route (/user/:id)
- Nested Routes
- Navigation using Link and NavLink
- Route Loaders with useLoaderData

## Tech Stack

- React
- React Router DOM
- Vite
- Tailwind CSS
